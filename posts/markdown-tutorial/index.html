Markdown 教程#

  • 块级元素
    • 段落与换行
    • 标题
    • 引用
    • 列表
    • 代码块

    • 表格
  • 行内元素
    • 链接

    • 代码
    • 图片
    • 删除线
  • 其他
    • 自动链接

引用式#

你可以预先定义链接引用。格式如下：[id]: URL "标题"

标题也是可选的。然后在正文中引用链接，格式如下：[链接文本][id]

代码：

预览：

This is an example reference-style link.

具体规则为：

  • 方括号中包含链接标识符（不区分大小写，左侧最多可缩进三个空格）；
  • 后跟一个冒号；
  • 后跟一个或多个空格（或制表符）；
  • 后跟链接的 URL；
  • 链接 URL 可以选择用尖括号包围；
  • 可选地后跟链接的标题属性，用双引号、单引号或圆括号包围。
