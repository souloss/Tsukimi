# Tsukimi Brand Migration Design

**Goal:** Rebrand the Mizuki codebase to "Tsukimi" (月见), making the project fully independent while preserving honest upstream attribution (Fuwari → Mizuki → Tsukimi).

**Architecture:** One-pass string replacement across all files, directory rename for content/docs, update CI/templates, swap logo/favicon files, and update README attribution chain.

**Tech Stack:** Shell sed/find, manual review for edge cases

## 6. Open Source License Compliance

The upstream project (Fuwari by saicaca) is released under the MIT license, which requires:

1. **Preserve the original copyright notice** in `LICENSE.MIT` — do not remove or modify the `Copyright (c) 2023 saicaca` line
2. **Preserve the MIT license text** in full — do not alter the license terms
3. **Add Mizuki's author copyright line** — LyraVoid is the author of Mizuki (the direct upstream of Tsukimi), their contribution must be attributed
4. **Add additional copyright lines for derivative work**, not replace the originals

After migration, the license file must contain:

```
Copyright (c) 2023 saicaca
Copyright (c) 2024-2026 LyraVoid
```

**Why these lines:**
- `saicaca` — original Fuwari author (the root upstream project)
- `LyraVoid` — Mizuki author (the direct upstream fork that Tsukimi is based on)
- Tsukimi is a fork of Mizuki; no separate copyright line is needed for Tsukimi itself as it is a derivative work, not an independent creation

**Verification checklist before merge:**
- [ ] `LICENSE.MIT` contains both copyright lines (saicaca + LyraVoid as Mizuki author)
- [ ] MIT license text is unchanged
- [ ] README contains attribution chain linking to both Fuwari and Mizuki
- [ ] No upstream author attribution has been removed from any file that originally contained it
- [ ] All third-party dependencies' licenses are still respected (no changes to dependency licensing)

## 7. Attribution Chain (README)

Replace current single upstream attribution with the full chain:

```
Tsukimi is based on [Mizuki](https://github.com/LyraVoid/Mizuki) by LyraVoid,
which is based on [Fuwari](https://github.com/saicaca/fuwari) by saicaca.
```

LICENSE.MIT: append Mizuki author copyright line:

```
Copyright (c) 2023 saicaca
Copyright (c) 2024-2026 LyraVoid
```

Where `saicaca` is the Fuwari original author and `LyraVoid` is the Mizuki author.

## 10. Execution Strategy

1. Create a new branch `brand/tsukimi`
2. Delete obsolete sync scripts: `scripts/sync-docs-mizuki.mjs`, `scripts/check-docs-mizuki.mjs`
3. Remove sync script entries from `package.json`
4. Rename directories: `src/content/docs/mizuki/` → `tsukimi/`
5. Run bulk string replacement: `Mizuki` → `Tsukimi`, `mizuki` → `tsukimi`, `MIZUKI` → `TSUKIMI`
6. Fix edge cases (event names, camelCase identifiers, URL paths)
7. Update CI/templates/assignees
8. Replace logo/favicon files (placeholder images for now)
9. Update README attribution chain
10. Update LICENSE.MIT (add LyraVoid copyright line, keep saicaca line)
11. Verify open source license compliance (run checklist from Section 6)
12. Build and verify (`pnpm build` — Pagefind index will be rebuilt automatically)
13. Force-overwrite v10.0.0 tag: `git tag -f v10.0.0`, `git push -f origin v10.0.0`
